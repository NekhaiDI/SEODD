# SEODD — SEO-аудит и сравнение с конкурентами

Плагин для Claude Code / Claude Desktop. Обходит твой сайт и сайты
конкурентов, собирает SEO-метрики каждой страницы (title, description, H1,
объём текста, canonical, alt у картинок, микроразметка, скорость ответа),
проверяет **AI-видимость** (пускает ли robots.txt поисковых ботов ChatGPT,
Claude, Perplexity; есть ли llms.txt и Product/FAQ-разметка, которую читают
AI-агенты), строит HTML- и Excel-отчёты и даёт план: что чинить сейчас,
что — потом.

Никаких Ahrefs/Semrush и ключей API не нужно — только прямой обход сайтов.

## Установка

### Claude Code (терминал)

Введи в Claude Code одну команду:

```
/plugin marketplace add NekhaiDI/SEODD
```

Затем:

```
/plugin install seo-audit-kit@seodd
```

Готово. Проверить можно командой `/plugin` — плагин должен быть в списке.

Claude Code — основной способ. Он есть не только в терминале: у него есть
своё десктопное приложение и расширение для VS Code — команды `/plugin ...`
работают там так же.

### Claude Desktop (чат-приложение)

В чат-приложении Claude Desktop нет маркетплейса плагинов — туда можно
подключить только сам скилл:

1. Скачай папку `skills/seo-audit` из этого репозитория и упакуй её в ZIP
   (внутри должен быть `SKILL.md`).
2. В Claude Desktop открой **Settings → Capabilities → Skills** и загрузи
   ZIP.

**Важно:** в чате код выполняется в облачной песочнице Anthropic — доступ к
произвольным сайтам оттуда может быть ограничен, и краулер не сможет
обойти сайты. Если аудит не запускается — используй Claude Code
([claude.com/code](https://claude.com/code)): там всё работает локально,
это рекомендуемый путь.

### Что нужно на компьютере

Ничего заранее ставить не обязательно: при первом запуске Claude сам
проверит окружение и установит недостающее — менеджер
[uv](https://docs.astral.sh/uv/), Python 3.11+ и библиотеки. Работает на
macOS, Windows и Linux.

Опционально: для браузерных проверок (скорость, мобильная версия) нужен
Chrome и Node 22+; на Windows — ещё Git Bash (ставится вместе с Git).

## Как пользоваться

Просто попроси Claude словами:

- «**Проведи SEO-аудит моего сайта**» — при первом запуске Claude спросит
  адрес сайта и конкурентов (или предложит настройки по умолчанию).
- «**Добавь конкурента example.by**» / «**Убери конкурента X**» — список
  сравнения меняется одной фразой, никаких конфигов руками.
- «**Что чинить в первую очередь?**» — получишь план: быстрые победы на
  эту неделю и стратегические задачи на квартал.
- «**Видит ли нас ChatGPT? А в AI-поиске мы есть?**» — проверка
  AI-видимости входит в аудит: robots.txt по AI-ботам, llms.txt, разметка
  товаров.
- «**Проверь, как сайт выглядит на мобильном**» / «**Замерь скорость**» —
  подключится браузерная проверка через Chrome.
- «**Добавь метрику X в отчёт**» — инструмент дорабатывает сам себя под
  твою задачу.

Первый прогон Claude сделает быстрым (до 50 страниц на сайт), чтобы
убедиться, что всё работает, и предложит полный. Полный аудит (до 600
страниц на сайт) занимает 5–20 минут.

## Что получишь

- **HTML-отчёт** — сравнительная таблица по всем сайтам (лучшие значения
  подсвечены) + список проблемных страниц. Открывается в браузере.
- **Excel-отчёт** — та же сводка + постраничные данные по каждому сайту:
  фильтруй, сортируй, строй сводные таблицы.
- **План работ** прямо в чате — по серьёзности и трудозатратам.

Все файлы сохраняются в папку `seo-audit/` рядом с тем местом, где ты
работаешь, конфигурация — в `seo-audit.config.json`. История прогонов
накапливается — можно просить Claude сравнить динамику.

## Состав плагина

| Компонент | Что делает |
|---|---|
| Скилл `seo-audit` | Краулер + анализ + отчёты + методология интерпретации; умеет дорабатывать сам себя |
| Скилл `browser-verify` | Проверки в реальном Chrome: скорость, Core Web Vitals, мобильная эмуляция, SPA-рендеринг, axe-аудит доступности |
| Агент `seo-analyst` | Автономно выполняет весь аудит и возвращает готовый план работ |
